# EDA Report for Gender Inequality Index Dataset

## 1. Correlation Matrix
The correlation matrix shows the relationships between numerical features in the dataset. Strong correlations can indicate potential multicollinearity or relationships between features.

## 2. Feature Distributions
The distribution of the features was examined. Some features follow normal distributions, while others may require transformations.

## 3. Target Distribution (GII VALUE)
The distribution of the target variable (GII VALUE) was plotted. This will help identify any skewness or outliers in the target variable.

## 4. Missing Values
A heatmap of missing values revealed that there were no significant missing data after imputation, ensuring the dataset's completeness.
